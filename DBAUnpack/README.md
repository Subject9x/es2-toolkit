### DBAUnpack
tool for unpacking Earhthsiege2 / ThreeSpace 2.0 DBA files into individual `.DBM` files.

+ Requires Java 19+ to be installed.

Steps
1. Extract `DBAUnpack.jar` to anywhere.
2. in command prompt
    + `java -jar DBAUnpack.jar`
3. Copy unpack.txt script to the target folder you want to compile a DBA in.
4. Fill out fields of the script.
5. Follow install steps in command prompt.
