### DBMUnpack
tool for unpacking Earhthsiege2 / ThreeSpace 2.0 DBM files into individual `.PNG` files.

works just like DBAUnpack but targets an entire directory of .DBM files instead of 1 at a time.

+ Requires Java 19+ to be installed.

Steps
1. Extract `DBMUnpack.jar` to anywhere.
2. in command prompt
    + `java -jar DBMUnpack.jar`
3. Copy unpack.txt script to the target folder you want to compile a DBA in.
4. Fill out fields of the script.
5. Follow install steps in command prompt.
