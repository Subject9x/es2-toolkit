### DBMConvert
tool for converting `.png` image files to Earhthsiege2 / ThreeSpace 2.0 `.DBM` files

+ Requires Java 19+ to be installed.

Steps
1. Extract `DBMConvert.jar` to anywhere.
2. in command prompt
    + `java -jar DBMConvert.jar`
3. Copy assembleDBA.txt script to the target folder you want to compile a DBA in.
4. Fill out fields of the script.
5. Follow install steps in command prompt.
